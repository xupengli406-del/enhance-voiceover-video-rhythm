# 口播视频节奏增强 Skill

为信息型口播、知识讲解和 MG 视频选择需要强调的位置。让观众知道此刻看哪里，并在动作之后留下能读懂的完成态。

## 它负责什么

- 根据当前问题区分“太平、太乱、重点不清、证据不可读”。
- 选择放大、缩小、局部蒙版、抠像、情境插图、移动或变形；不按时间平均加效果。
- 给每个效果写明真实口播锚点、唯一焦点、动作、完成态与停留时间。
- 控制同屏竞争和动效密度，检查手机阅读与声画同步。

本仓库主要是制作指导与方法库，没有独立视频渲染器。它要由 AI 接入已有工程；不替代写稿、配音、字幕校对或完整成片验收。

## 怎么开始

下载或克隆完整仓库，保留 `SKILL.md`、`references` 和 `agents`，放入所用 AI 工具配置的 Skills 目录，文件夹名保持为 `enhance-voiceover-video-rhythm`。Codex 用户也可以让内置 `$skill-installer` 从本仓库安装。

提供已经审过的口播、最终声音与时间锚点、现有画面或可编辑工程，再说明最想解决的问题。

> 使用 enhance-voiceover-video-rhythm 检查这段口播视频。我觉得【太平／太乱／重点不清／资料看不清】。在真实发声锚点上调整画面，先给出处理图，再做覆盖一个完整意思的短样片。保留稳定构图，不用持续晃动来填满时间。

还没有完整制作流程时，可同时使用 [主 MG Skill](https://github.com/xupengli406-del/produce-voiceover-mg-social-video)；封面由 [封面 Skill](https://github.com/xupengli406-del/produce-social-media-cover)负责。

## 阅读与验证

- [SKILL.md](SKILL.md)：使用边界、注意力预算、接入顺序和验收要求。
- [treatment-library.md](references/treatment-library.md)：每类处理的适用条件、禁用信号与处理图字段。
- 先做短样片，检查实际完成态、字幕与证据是否可读，再按 1× 速度检查声画关系。不存在一个分数或脚本能替代这一步。

效果由现有工程和工具实现，费用及运行依赖随所用工具而定。这里不提供配音服务、素材账号或原作者的私人媒体。

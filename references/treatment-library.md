# 口播画面处理方法库

只读取与当前画面问题相关的条目。方法名称描述视觉语法，不代表必须使用。

## 1. 重点词放大

适合核心名词、反差答案和最终结论。保持周围结构不变，只让一个词或一个对象完成一次受控放大，然后停住。

禁用信号：一句话里连续放大多个词；放大同时伴随换背景、旋转、闪色和镜头推拉；文字大到破坏断行或安全区。

## 2. 负面词缩小或退后

适合表现“减少、失去、无效、退出、被削弱”。缩小必须表达状态变化，而不是因为负面词出现就机械缩放。

禁用信号：主体缩小后不可读；负面信息反而因抖动或强色更加抢眼；同一段反复忽大忽小。

## 3. 局部蒙版或聚光

适合截图、人物或多元素画面中的单一证据点。优先保持来源全貌，再局部压暗非目标区域或使用不遮字的框线、下划线和外置标签。

禁用信号：整屏长期昏暗；蒙版遮住来源、上下文或正文；目标切换太快，观众来不及确认内容。

## 4. 抠像或分层

适合人物口播、多观点切换、前景与背景需要建立空间层级的场景。抠像后的移动应该帮助视线转向新证据或新观点。

禁用信号：只是为了让画面更满；人物边缘质量差；人物、字幕和信息卡同时移动；无真人出镜时用伪人物替代事实证据。

## 5. 事实插图

适合把抽象事实落到具体物体、场景或因果关系。插图只承担解释和情境，不冒充产品界面、真实数据或官方证据。

禁用信号：插图与当前口播只有关键词联想，没有解释价值；相邻场景连续换图造成图片轮播；事实证据被装饰图压缩得不可读。

## 6. 关键帧移动

适合路径、交接、流向、前后关系和空间位置变化。运动必须有明确起点、终点和完成态；整段只追踪一个主体。

禁用信号：背景与主体一起漂；路径穿过文字或卡片；为了“保持活跃”让静态信息持续缓慢移动；运动结束没有结果回写。

## 7. 形态变形

适合少量创意转折，例如一个对象变成另一种状态、错误结构被压扁或信息从碎片聚合成整体。它是高强度方法，通常只用于开头、章节翻转或结论回收。

禁用信号：纯文字频繁扭曲；形变过程比信息本身更难理解；技术术语、品牌名或证据文本被变形影响识别。

## 推荐组合

### 稳定信息解释

以静态母版为主，只使用一次重点放大、一次证据聚光和一次关系移动。适合概念、研究结论和官方案例。

### 真人口播

以人物为稳定主体，选择局部抠像、少量关键词强调和事实插图。人物、字幕和背景不要同时运动。

### 机制演示

用关键帧移动承担核心机制；其他段落保持稳定。需要结论翻转时最多补一次形态变化。

## 密度失败时的减法顺序

1. 关闭持续背景运动和无意义微动。
2. 删除与发声锚点无关的装饰动画。
3. 把多个逐项入场合并为一次整体更新。
4. 取消重复的缩放、弹跳、旋转和扫光。
5. 延长完成态停留，必要时减少场景数量。
6. 若仍然混乱，回到口播与语义窗检查信息是否本身过载。

## 处理图最小字段

| 字段 | 内容 |
|---|---|
| 时间窗 | 起止时间和语义窗 ID |
| 口播锚点 | 正在发声的短句 |
| 唯一焦点 | 观众此刻只需要看什么 |
| 方法 | 放大、缩小、蒙版、抠像、插图、移动、变形或静态 |
| 动作 | 对象从什么状态变成什么状态 |
| 完成态 | 动效结束后保留的可读画面 |
| 停留 | 完成态持续多久 |
| 排除项 | 为什么不用其他效果 |
